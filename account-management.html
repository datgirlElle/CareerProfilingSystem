Sections

Sections offered per strand, used for the class roster, assessment scheduling, and student records. Deactivating one keeps existing students' data intact but stops it being offered for new schedules and roster uploads.

A section code is one letter and four digits, like S1114. The letter matches the strand (S for STEM, A for ABM, I for ICT, H for HUMSS) and the first two digits are the grade level (11 or 12).

Class Roster

Upload the list of students expected this Academic Year. Students on the roster who haven't registered yet show as Not Registered on Student Information.

  1. Download the template. Type the Strand and Section once at the top (a section code is one letter and four digits, like S1114: S for STEM, A for ABM, I for ICT, H for HUMSS). Then list each student's Student Number (10 to 12 digits), Student Name as LASTNAME, FIRSTNAME MIDDLE, and the student's email (@live.mcl.edu.ph). The email is required for every student.
  2. Save it as a .csv or Excel (.xlsx) file and upload it here. Each file is one section; upload a section again to replace just that section's list. Students can register only if their Student Number is on the roster, and the Academic Year is set automatically.
