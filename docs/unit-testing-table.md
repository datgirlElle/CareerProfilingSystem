No test code and no source code was changed to obtain these results.
**Manuscript status:** Chapters 4 and 5 were **not available** in the repository or in the request. No claim of alignment with the manuscript is made. Issues listed below come from repository documents only (`tests/TEST_REPORT.md`, `docs/methodology-notes.md`). Please supply the chapters so the cross-check can be completed.

Status values: **Pass** = actual result met the expected result in this run; **Fail** = it did not; **Blocked** = a precondition was missing, so the case could not run; **Not Executed** = no test exists or it was not run.
"Evidence" = script and its printed summary line from this run (`php tests/<script>.php`).
