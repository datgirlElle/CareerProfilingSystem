CBF Calculation

Content-based filtering: the student's RIASEC profile compared with every course's RIASEC code using cosine similarity, cos(S, C) = (S · C) / (||S|| × ||C||). Cosine similarity is a 0-1 similarity score, not an accuracy or a percentage.

1. Student RIASEC profile → student vector S

2. Every course → course vector C → cosine similarity

Course vector: 1 if the letter is in the course's RIASEC code, 0 if not, in [R, I, A, S, E, C] order. Sorted by cosine similarity; green rows are the Best RIASEC Match (highest cosine similarity, ties kept), blue rows the Alternative Courses (next-highest).
